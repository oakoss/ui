oakoss/ui is a set of React components you copy into your project with the shadcn CLI. Each one is built on [React Aria Components](https://react-aria.adobe.com/) for behavior and accessibility, and styled with Tailwind CSS.

## Installation

Set up your project once, then add components straight from this repository.
See [Installation](/docs/installation).
