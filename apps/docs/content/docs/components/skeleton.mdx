## Accessibility

A skeleton is `aria-hidden`: its shape carries no information, and a screen
reader reading a row of empty boxes would only add noise. Say that content is
loading on the region instead, with `aria-busy="true"`, and replace the
skeletons with the content when it arrives. React Aria adds no keys.

The pulse is a CSS animation, which the theme's reduced-motion layer stops for
people who ask for less motion, leaving the shape still. In Windows High
Contrast the fill takes the page color, and the skeleton's border outlines the
shape instead.

## API

### Skeleton

A `div` with a muted fill and a pulse. `className` sets its size and shape,
such as `h-4 w-48` for a line or `size-10 rounded-full` for an avatar.

#### Props

Accepts `div` props. Pass `aria-hidden={false}` only if the skeleton itself
should be announced.

#### Data attributes

| Attribute   | Present when       |
| ----------- | ------------------ |
| `data-slot` | Always: `skeleton` |
