## Usage

`FieldLabel`, `FieldDescription` and `FieldError` find their field through
React Aria's context. Inside any React Aria field (`TextField`, `SearchField`,
`NumberField`, `Select`, `ComboBox`, `DatePicker` and others) they link to the
input for screen readers with no ids to wire.

```tsx
import { SearchField } from 'react-aria-components';

import { FieldDescription, FieldLabel } from '#/components/ui/inputs/field';
import { Input } from '#/components/ui/inputs/input';

<SearchField>
  <FieldLabel>Search docs</FieldLabel>
  <Input />
  <FieldDescription>Press / to focus.</FieldDescription>
</SearchField>;
```

## Examples

### Errors

`errors` on `FieldError` takes a form library's errors (strings, or objects
with a `message`); duplicates, blank entries and anything else are dropped, and
several errors render one per line. Children win over `errors` unless empty
(`cond && 'Message'`). With neither, it shows React Aria's validation messages.
It renders only while its field is invalid.

`size` on `Input` (`sm`, `md`, `lg`) sets the control height, which matches

### Orientation

`orientation` on `Field` lays out a label beside its control. Put `Field`
inside the React Aria field, so the field still wires its label and
description. `horizontal` keeps them in a row, and a `FieldContent` column
next to a control lines the row up at its top. `responsive` is a row once the
nearest `FieldGroup` is 28rem wide and stacks below that; outside a
`FieldGroup` it always stacks. A stacked `Field` stretches every child to its
width, a Button included.

## Accessibility

React Aria links the parts through context:

- **Name and description:** `FieldLabel` names the input, and
  `FieldDescription` and `FieldError` describe it, with no ids to wire.
- **Errors:** `FieldError` renders only while the field is invalid, so screen
  readers never read a stale message. Several errors are read in one pass,
  with a space between them so their words don't run together.
- **Groups:** `FieldSet` is a native `<fieldset>`, and `FieldLegend` its
  `<legend>`, which screen readers announce on entering the group.
- **Layout parts:** `Field` and `FieldContent` are plain `<div>`s with no role,
  so they add nothing for screen readers to announce. A `FieldSeparator` with
  text reads as one separator, then its text.
- **Other controls:** a `FieldLabel` with `htmlFor` names that control only,
  even inside a React Aria field.

`Input`'s border reaches 3:1 against the page at rest and when invalid.

The input keeps the browser's own keyboard behavior; React Aria adds no keys.

## API

### FieldError

Extends React Aria's [`FieldError`](https://react-aria.adobe.com/forms).

#### Props

Also accepts all React Aria `FieldError` props.

#### Data attributes

| Attribute   | Present when         |
| ----------- | -------------------- |
| `data-slot` | Always `field-error` |

### Input

Extends React Aria's [`Input`](https://react-aria.adobe.com/TextField#api).

#### Props

<auto-type-table
  path="../../../../../packages/ui/src/components/ui/inputs/input.tsx"
  name="InputProps"
/>

Also accepts all React Aria `Input` props except HTML's `size`.

#### Data attributes

| Attribute            | Present when          |
| -------------------- | --------------------- |
| `data-slot`          | Always `input`        |
| `data-size`          | Always; the height    |
| `data-hovered`       | A pointer hovers it   |
| `data-focused`       | It has focus          |
| `data-focus-visible` | It has keyboard focus |
| `data-disabled`      | Its field is disabled |
| `data-invalid`       | Its field is invalid  |

### Field

A `<div>` that lays out a label, description and control.

#### Props

<auto-type-table
  path="../../../../../packages/ui/src/components/ui/inputs/field.tsx"
  name="FieldProps"
/>

Also accepts `div` props.

#### Data attributes

| Attribute          | Present when                                     |
| ------------------ | ------------------------------------------------ |
| `data-slot`        | Always `field`                                   |
| `data-orientation` | Always; `vertical`, `horizontal` or `responsive` |

### FieldSeparator

A `<div>` around a line, or two lines with text between them. Accepts `div`
props.

| Attribute      | Present when                                                    |
| -------------- | --------------------------------------------------------------- |
| `data-slot`    | Always `field-separator`; `field-separator-content` on the text |
| `data-content` | Always; `true` when it has text                                 |

### Other parts

These add no props of their own, and each sets a `data-slot`:

| Part               | Extends                                       | `data-slot`         |
| ------------------ | --------------------------------------------- | ------------------- |
| `FieldLabel`       | React Aria's `Label`                          | `field-label`       |
| `FieldDescription` | React Aria's `Text` with `slot="description"` | `field-description` |
| `FieldSet`         | `<fieldset>`                                  | `field-set`         |
| `FieldGroup`       | `<div>`, a container for responsive fields    | `field-group`       |
| `FieldContent`     | `<div>`                                       | `field-content`     |
