## Usage

```tsx
import {
  Command,
  CommandInput,
  CommandItem,
  CommandList,
} from '#/components/ui/overlays/command';

<Command>
  <CommandInput placeholder="Type a command" />
  <CommandList aria-label="Commands" onAction={(key) => run(key)}>
    <CommandItem id="new" keywords={['create']} shortcut="⌘N">
      New file
    </CommandItem>
  </CommandList>
</Command>;
```

What's typed filters the list, ignoring case and accents, and matches an
item's label and its `keywords`. Items take Dropdown Menu's item props:
`shortcut`, `description`, `intent` and `href`. `CommandGroup` sections the
list under a `CommandHeader`, each section after the first drawing a line
above it.

`CommandDialog` puts a command in a modal, named by `title` and focused on

## Accessibility

React Aria links a search field to a `menu` of results:

- **Focus:** focus stays in the input. The highlighted item is the input's
  `aria-activedescendant`, so screen readers read it as the arrow keys move.
- **Names:** the input is named `Search` unless you name it with
  `aria-label` or `aria-labelledby`, and the list by its own `aria-label`.
  A group is named by its `CommandHeader`, and a shortcut or description
  describes its item.
- **Results:** items are `menuitem`s, since they run commands. When nothing
  matches, the list shows `emptyLabel`.

In Windows High Contrast the highlighted item takes the system's selection
colors.

| Key      | Action                                           |
| -------- | ------------------------------------------------ |
| Typing   | Filters the list                                 |
| ↓, ↑     | Moves the highlight through the results          |
| `Enter`  | Runs the highlighted command                     |
| `Escape` | Clears the search, then closes a `CommandDialog` |

#### Data attributes

| Attribute             | Present when                                           |
| --------------------- | ------------------------------------------------------ |
| `data-slot`           | Always `command-item`                                  |
| `data-intent`         | Always: `neutral` or `destructive`                     |

### Other parts

| Part               | Extends                                          | `data-slot`             |
| ------------------ | ------------------------------------------------ | ----------------------- |
| `CommandInput`     | React Aria's `SearchField`, with an `InputGroup` | `command-input-wrapper` |
| `CommandGroup`     | React Aria's `MenuSection`                       | `command-group`         |
| `CommandHeader`    | React Aria's `Header`, with `inset`              | `command-label`         |
| `CommandSeparator` | React Aria's `Separator`                         | `command-separator`     |

`CommandInput`'s input is `command-input`, and `Command` is `command`.
`CommandInput` takes React Aria's `SearchField` props except `value` and
`defaultValue`: `Command` owns what's typed, through `inputValue`,
`defaultInputValue` and `onInputChange`.
