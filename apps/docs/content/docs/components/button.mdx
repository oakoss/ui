## Usage

```tsx
import { Button } from '#/components/ui/inputs/button';

<Button intent="success" variant="soft">
  Save
</Button>;
```

## Examples

### Variants and intents

`variant` sets the look (`solid`, `soft`, `outline`, `ghost`, `link`) and
`intent` sets the color (`primary`, `neutral`, `destructive`, `success`,
`warning`, `info`). Every look works with every intent.

</ComponentPreview>

### Custom colors

`className` can set the `--btn-*` variables that every look reads. Set them
rather than overriding `bg-*`, which hover and press would replace. See
[CSS variables](#css-variables) for each one.

### Icon-only

`size="icon"` (or `icon-sm`, `icon-lg`) requires an `aria-label` or
`aria-labelledby`, since there's no text to name the button.

### Pending

`isPending` keeps the button's width and focus, blocks presses, and shows a
spinner. Set `pendingLabel` to translate the spinner's name (see
[Localization](/docs/guides/localization)).

## Accessibility

React Aria renders a native `<button>` and handles:

- **Press:** one event for mouse, touch, pen and keyboard, so `onPress` fires
  once however the button is used.
- **Focus:** the focus outline shows for keyboard focus only
  (`data-focus-visible`).
- **Pending:** the button stays focusable but ignores presses, and screen
  readers announce the change while it has focus.

This component adds a 44×44 pointer target around every size, and keeps a
visible border in Windows High Contrast. Icon-only sizes require a name in the
type.

| Key     | Action             |
| ------- | ------------------ |
| `Space` | Presses the button |
| `Enter` | Presses the button |

Follows the [WAI-ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

Also accepts all [React Aria `Button` props](https://react-aria.adobe.com/Button#api).

#### Data attributes

| Attribute            | Present when                              |
| -------------------- | ----------------------------------------- |
| `data-slot`          | `button`, unless a wrapper passes its own |
| `data-variant`       | Always; the look                          |
| `data-intent`        | Always; the color                         |
| `data-size`          | Always; the size                          |
| `data-hovered`       | A pointer hovers it                       |
| `data-pressed`       | It's being pressed                        |
| `data-focused`       | It has focus                              |
| `data-focus-visible` | It has keyboard focus                     |
| `data-disabled`      | `isDisabled` is set                       |
| `data-pending`       | `isPending` is set                        |

#### CSS variables

| Variable       | Sets                                                |
| -------------- | --------------------------------------------------- |
| `--btn-bg`     | The solid fill                                      |
| `--btn-hover`  | The solid fill on hover and press                   |
| `--btn-fg`     | Text on the solid fill                              |
| `--btn-subtle` | The soft fill                                       |
| `--btn-border` | The outline border                                  |
| `--btn-text`   | Text, and the hover and press tint, for other looks |
