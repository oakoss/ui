## Usage

```tsx
import {
  Popover,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from '#/components/ui/overlays/popover';

<PopoverTrigger>
  <Button>Open</Button>
  <Popover>
    <PopoverHeader>
      <PopoverTitle>Title</PopoverTitle>
      <PopoverDescription>Description</PopoverDescription>
    </PopoverHeader>
  </Popover>
</PopoverTrigger>;
```

## Accessibility

Popover wraps its content in React Aria's
[Dialog](/docs/components/dialog#accessibility), so `PopoverTitle` names it.
Like Dialog, the description isn't linked, so screen readers don't read a long
popover in full when it opens; pass `aria-describedby` with the description's
`id` to have a short one read. A popover without a title needs an
`aria-label`.

React Aria moves focus into the popover on open, keeps it there, and returns it
to the trigger on close. Escape and a click outside close it. `start` and `end`
placements follow the locale's direction. Tall content without a control in it
goes in `PopoverBody`, which keyboard users can focus to scroll.

The panel keeps a border in Windows High Contrast, where the arrow takes the
system colors.

Follows the [WAI-ARIA dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

## API

### Popover

Renders React Aria's [`Popover`](https://react-aria.adobe.com/Popover#api)
with a `Dialog` inside. `className` applies to the panel. Its z-index is the
`z-(--z-popover)` class, which a `z-*` class in `className` overrides; Popover
clears the 100000 React Aria sets inline. A dialog opened from an open popover
renders below it, so close the popover first.

Also accepts [React Aria `Popover` props](https://react-aria.adobe.com/Popover#api)
except `isNonModal`, since the dialog inside always contains focus; `children`
and `className` take plain values, not render functions.
`placement` defaults to `bottom`, and `offset` to 8, or 12 with an arrow. On a
phone, a trigger in the middle of the screen leaves no room beside it, so
prefer `top` or `bottom` over `start` and `end` there.

#### Data attributes

| Attribute        | Present when                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| `data-slot`      | Always: `popover-content` (the panel), `popover` (the dialog); `popover-arrow` with `showArrow` |
| `data-placement` | Always; the side the panel opened on (`top`, `bottom`, `left`, `right`)                         |
| `data-entering`  | The panel is fading in                                                                          |
| `data-exiting`   | The panel is fading out                                                                         |

### PopoverHeader, PopoverTitle, PopoverDescription, PopoverBody, PopoverTrigger

Dialog's parts with `popover-*` `data-slot`s (`PopoverBody` keeps
`dialog-body`), sized for a popover.

### popoverStyles, PopoverArrow

The panel's classes (`popoverStyles({ className })`, where `className` wins)
and its arrow, for another React Aria `Popover` to share, as
[Hover Card](/docs/components/hover-card) does.
