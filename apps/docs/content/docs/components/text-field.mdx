## Installation

<ComponentInstall item="text-field" />

This also installs [Field](/docs/components/field), whose parts TextField
renders.

## Usage

```tsx
import { TextField } from '#/components/ui/inputs/text-field';

<TextField
  description="We never share your address."
  label="Email"
  type="email"
/>;
```

For multiline text, `TextareaField` takes the same props with a growing
[Textarea](/docs/components/textarea) in place of the input.

### Validation

`errors` takes a form library's errors: strings, or objects with a `message`,
as TanStack Form and React Hook Form produce. Several errors render one per
line. Derive `isInvalid` from the same state, so the field clears when the
errors do. Type a `.com` address to clear them:

<ComponentPreview name="text-field-validation">
  <TextFieldValidation />
</ComponentPreview>

With TanStack Form, that's
`errors={field.state.meta.errors} isInvalid={!field.state.meta.isValid}`. The error shows only while the field is invalid, so `errors` without
`isInvalid` renders nothing, and `errorMessage` wins over `errors`. Without
either, React Aria's own validation (`isRequired`, `validate`, `type="email"`)
supplies the message. For a whole form, see
[TanStack Form](/docs/guides/tanstack-form).

### Custom layout

`children` replace the default layout. Compose the
[Field](/docs/components/field) parts, which wire up the label, description and
error the same way:

<ComponentPreview name="text-field-custom-layout">
  <TextFieldCustomLayout />
</ComponentPreview>

Children and the layout props (`label`, `description`, `errorMessage`,
`errors`, `placeholder`, `size`) can't be mixed; set those on the parts
instead.

## Accessibility

React Aria renders a native `<input>` and links it to its parts:

- **Name and description:** the label names the input, and the description and
  error describe it (`aria-labelledby`, `aria-describedby`), with no ids to
  wire.
- **Validation:** an invalid field sets `aria-invalid`, and `isRequired` sets
  the native `required` attribute (`aria-required` with
  `validationBehavior="aria"`). The required asterisk is hidden from screen
  readers, which already announce the field as required.

The border reaches 3:1 against the page at rest and when invalid, and the focus
outline shows for any focus, mouse included.

The input keeps the browser's own keyboard behavior; React Aria adds no keys.

## API

### TextField

Extends React Aria's [`TextField`](https://react-aria.adobe.com/TextField#api).
With `children`, it renders only them; the parts are on the
[Field](/docs/components/field#api) page.

#### Data attributes

| Attribute       | Present when         |
| --------------- | -------------------- |
| `data-slot`     | Always `text-field`  |
| `data-disabled` | `isDisabled` is set  |
| `data-invalid`  | The field is invalid |
| `data-readonly` | `isReadOnly` is set  |
| `data-required` | `isRequired` is set  |
