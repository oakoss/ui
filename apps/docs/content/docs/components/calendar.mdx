## Usage

```tsx
import { getLocalTimeZone, today } from '@internationalized/date';
import { Calendar } from '#/components/ui/inputs/calendar';

<Calendar aria-label="Delivery date" minValue={today(getLocalTimeZone())} />;
```

Values are `@internationalized/date` objects (`CalendarDate`, `CalendarDateTime`
or `ZonedDateTime`), which the item installs; React Aria doesn't re-export
`today`, `parseDate` or the other helpers. `selectionMode="multiple"` picks
several dates. A calendar always shows six weeks, so it keeps its height from
month to month; `weeksInMonth` changes that.

A calendar suits dates close to now. For a date of birth or another distant
date, typing is faster, so use a date field instead.

### Presets

keep their own names and handlers, and one with `slot="close"` closes the

## Accessibility

React Aria renders a [grid](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/datepicker-dialog/)
of days inside an `application`, and links it up:

- **Name:** the calendar is named by `aria-label` and the visible months, and
  each day by its full date, with "Today" and "selected" in the user's
  language.
- **Navigation:** the steppers are named "Previous" and "Next" in the user's
  language, and the month heading is announced when it changes.
- **Validation:** a day's error comes from `errorMessage`; an unavailable or
  disabled day is `aria-disabled`.

Days are 36px and grow to 44px wherever a touch pointer is present. Today has a
dot, never a fill, so it stays visible inside a range. In Windows High
Contrast the selected day takes the system's selection colors, an invalid one
takes Mark, and the range keeps a border.

| Key                           | Action                                             |
| ----------------------------- | -------------------------------------------------- |
| ←, →                          | Moves to the previous or next day                  |
| ↑, ↓                          | Moves to the same day in the previous or next week |
| `Home`, `End`                 | Moves to the first or last day of the month        |
| `PageUp`, `PageDown`          | Moves to the previous or next month                |
| `Shift` + `PageUp`/`PageDown` | Moves to the previous or next year                 |
| `Enter`, `Space`              | Selects the day, or a range's start then its end   |
| `Escape`                      | Cancels a range picked halfway                     |

The arrow keys follow the reading direction in right-to-left locales.

Today and the month shown first come from the visitor's clock and time zone.
A page rendered on the server, or prerendered on an earlier day, disagrees with
the browser, and React reports a hydration error, so render calendars on the
client only, as this page does.

Also accepts all [React Aria `Calendar` props](https://react-aria.adobe.com/Calendar#api)
except `visibleDuration`, which `visibleMonths` sets. Children replace the
layout.

### RangeCalendar

Extends React Aria's [`RangeCalendar`](https://react-aria.adobe.com/RangeCalendar#api),
with the same props as Calendar.

#### Data attributes

| Attribute       | Present when            |
| --------------- | ----------------------- |
| `data-slot`     | Always `calendar`       |
| `data-invalid`  | The calendar is invalid |
| `data-disabled` | `isDisabled` is set     |

### CalendarCell

Extends React Aria's [`CalendarCell`](https://react-aria.adobe.com/Calendar#calendarcell).

#### Data attributes

| Attribute              | Present when                         |
| ---------------------- | ------------------------------------ |
| `data-slot`            | Always `calendar-cell`               |
| `data-selected`        | The day is selected                  |
| `data-selection-start` | The day starts the range             |
| `data-selection-end`   | The day ends the range               |
| `data-today`           | The day is today                     |
| `data-unavailable`     | `isDateUnavailable` returns true     |
| `data-disabled`        | The day is out of bounds or disabled |
| `data-outside-month`   | The day belongs to another month     |
| `data-invalid`         | The selected day is invalid          |
