## Accessibility

React Aria renders a native checkbox inside a `<label>`, so the label is the
checkbox's name and its click target. Space toggles it.

- **Description and errors:** `description` and the error describe the
  checkbox, with no ids to wire. The error shows only while it's invalid.
  Inside a React Aria `CheckboxGroup`, the group shows the errors, and a
  checkbox's own `errorMessage` and `errors` don't render.
- **Required:** the asterisk after a required label is hidden from screen
  readers, and the checkbox is marked required. Chrome doesn't expose that
  state for checkboxes, so where it matters, say so in the label or
  description. Chrome also reports a required checkbox as invalid until it's
  checked, as it does any native one, so a screen reader may say "invalid"
  before the user has touched it; `validationBehavior="aria"` avoids that,
  but then the checkbox no longer blocks a native form submit.
- **Indeterminate:** screen readers announce it as mixed.
- **Target size:** the box's hit area grows to 44px. Set `targetSize={false}`
  where checkboxes sit closer than that, or neighbors take each other's
  clicks; the label row stays at least 24px tall.
- **Contrast:** the box's border reaches 3:1 against the page, and an
  invalid box keeps its error border when checked. In Windows High Contrast
  the box, fill and check take system colors; an invalid box keeps the
  normal border there, and the error text carries the state.

## API

### Checkbox

Renders React Aria's
[`CheckboxField`](https://react-aria.adobe.com/Checkbox#api), with its
label in a `CheckboxButton`. Children are the label.

#### Props

<auto-type-table
  path="../../../../../packages/ui/src/components/ui/inputs/checkbox.tsx"
  name="CheckboxProps"
/>

Also accepts React Aria `CheckboxField` props.

#### Data attributes

| Attribute            | Present when                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `data-slot`          | Always: `checkbox-field` on the root, `checkbox` on the label, `checkbox-indicator` on the box |
| `data-selected`      | It's checked                                                                                   |
| `data-indeterminate` | It's indeterminate                                                                             |
| `data-invalid`       | It's invalid                                                                                   |
| `data-disabled`      | It's disabled                                                                                  |
| `data-readonly`      | It's read-only                                                                                 |
| `data-required`      | It's required                                                                                  |
| `data-hovered`       | On the label, while a pointer hovers it                                                        |
| `data-pressed`       | On the label, while it's pressed                                                               |
| `data-focus-visible` | On the label, while it has keyboard focus                                                      |
