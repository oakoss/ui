## Usage

```tsx
import { ContextualHelp } from '#/components/ui/overlays/contextual-help';
import {
  PopoverBody,
  PopoverHeader,
  PopoverTitle,
} from '#/components/ui/overlays/popover';

<ContextualHelp>
  <PopoverHeader>
    <PopoverTitle>Title</PopoverTitle>
  </PopoverHeader>
  <PopoverBody>Explanation</PopoverBody>
</ContextualHelp>;
```

## Accessibility

The trigger is a [Button](/docs/components/button) named by `helpLabel`
("Help") or `infoLabel` ("Information"), so it works with a keyboard, a screen
reader and touch, where a [Tooltip](/docs/components/tooltip) doesn't open.
Enter or Space opens a [Popover](/docs/components/popover#accessibility),
which takes its name from a `PopoverTitle` in the content, or the button's
label without one. Focus moves into it, Tab stays inside, and Escape closes it
and returns focus to the button. A disabled field keeps its help reachable:
the button never takes a surrounding field's props, so it stays enabled
inside a disabled NumberField or Select and opens its own popover.

In Arabic, Persian and Urdu the help icon mirrors, as those scripts write the
question mark (؟); Hebrew, which uses "?", and the info icon don't.

Follows the [WAI-ARIA dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

## API

### ContextualHelp

Renders our [Popover](/docs/components/popover) with a ghost icon Button as
its trigger. `className` applies to the button.
