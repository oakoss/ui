Components read colors from CSS variables such as `--primary` and
`--muted-foreground`, never from the palette directly. Each table lists a
group's tokens with the palette color they resolve to and the value in the
CSS. Pick a family and flavor for each table, or the primary color for the
Primary table. Press a token's name to copy its `var()`.

In a component, use the Tailwind class for the token: `bg-primary`,
`text-muted-foreground`, `border-input`. See [Token
Names](/docs/theming/token-names) for how the names are built.

gray, so they don't change with the primary color.
